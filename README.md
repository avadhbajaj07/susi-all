# susi-all

Susi Davies website & studio admin workspace built with Next.js 16, Supabase, and Tailwind/Vanilla CSS.

## Features
- Marketing Pages (Home, Retreats, Coaching & Mentoring, Private Sessions, Yoga Dynamics App, Online Courses, Journal, Contact Us)
- Responsive Image-Led Design & Custom Dynamic Movement / Deeper Practice Components
- Interactive Testimonials & Image Carousels
- Supabase Integration Foundation
